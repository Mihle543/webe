#PROJECT OVERVIEW
WEBE is a user-focused website project development as part of the Web Development module at Rosebank International. The website aims to provide a clean, functional and responsive online presence for a small business. It addresses the real-world need for accessible information, clear navigation and contactability for potential clients.
#WEBSITE GOALS
Primary Goal: To develop a professional, responsive website (WEBE) that showcases services and improves user engagement.
Objective 1: Responsive UI that loads in under 3 seconds.
Objective 2: Clear navigation (Home, About, Services, Contract).
Objective 3: Basic accessibility and SEO compliance.
